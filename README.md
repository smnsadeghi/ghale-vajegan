# قلعه واژگان (PWA)

وب‌اپلیکیشن آموزشی ۱۶ بیتی رترو «معمای دروازه» برای آموزش واژه‌های ایهام‌دار و آرایه‌های ادبی کتاب ادبیات فارسی دهم.

## قابلیت‌ها
- **سبک بصری ۱۶ بیتی معمای دروازه (Retro Pixel Art):** آسمان ۵ لایه‌ای با دیترینگ، انیمیشن دروازه، مشعل‌های سلامتی، شوالیه، افکت‌های صوتی ۸ بیتی و بدون هیچ‌گونه ایموجی.
- **قابل نصب روی گوشی (PWA):** دارای `manifest.json` و `sw.js` برای نصب روی صفحه اصلی اندروید و iOS و اجرای آفلاین.
- **تکرار هوشمند (Spaced Repetition) و کمبوی x3:** مرور فلش‌کارت و آزمون ۴ گزینه‌ای RPG به همراه ضریب امتیاز کمبو.
- **احراز هویت شماره همراه:** ثبت و ورود با شماره ۱۱ رقمی همراه (09...) و رمز ۴ رقمی شخصی (هش‌شده با SHA-256).
- **پنل مخفی دبیر:** ۳ کلیک روی نسخه (`v3.0-pixel`) و رمز `431380`.
- **همگام‌سازی تفکیک‌شده ابری Supabase:** ذخیره ردیفی مستقل در جدول `gv_students` بدون تداخل همزمانی، و پیکربندی مراحل و قفل کلاس در `gv_state`.

## نحوه انتشار رایگان روی GitHub Pages
1. یک مخزن (Repository) جدید در GitHub بسازید (مثلاً `ghale-vajegan`).
2. هر ۴ فایل داخل این پوشه (`index.html`, `manifest.json`, `sw.js`, `icon.svg`) را در مخزن آپلود و Commit کنید.
3. در مخزن به بخش **Settings > Pages** بروید.
4. در قسمت **Branch**، شاخه `main` و پوشه `/ (root)` را انتخاب کرده و **Save** را بزنید.
5. پس از حدود ۱ دقیقه لینک اپلیکیشن شما آماده است و با باز کردن آن در Chrome، دکمه **نصب برنامه** برای دانش‌آموزان ظاهر می‌شود.

## فعال‌سازی دیتابیس ابری زنده (اختیاری)
اگر می‌خواهید امتیازها و رتبه‌بندی تمام دانش‌آموزان از گوشی‌های مختلف در یک جدول واحد جمع شود:
1. در سایت رایگان [Supabase](https://supabase.com) یک پروژه بسازید و در بخش SQL Editor دستور زیر را اجرا کنید:
```sql
create table gv_state (
  id text primary key,
  payload jsonb
);
alter table gv_state enable row level security;
create policy "public_access" on gv_state for all using (true) with check (true);
```
2. در پنل مدیریت دبیر درون اپلیکیشن، آدرس `Project URL` و کلید `anon public` را وارد و ذخیره کنید.
