# قلعه واژگان (Ghāle Vāzhegān) — نسخه v3.6-visual
## وب‌اپلیکیشن آموزشی ۱۶ بیتی دارک فانتزی «معمای دروازه» برای ادبیات فارسی دهم

وب‌اپلیکیشن پیش‌رونده (PWA) با سبک بصری الهام‌گرفته از بازی‌های سینمایی دارک فانتزی ۱۶ بیتی (*Eastward*) برای یادگیری، مرور فاصله‌دار و تسلط بر واژگان، کنایه‌ها و ایهام‌های کتاب درسی ادبیات فارسی پایه دهم.

---

## قابلیت‌های نسخه جدید (v3.6-visual)

### ۱. بازطراحی کامل بصری نبردگاه (Battle Arena)
- **موتور بصری چندلایه‌ای هیبرید (DOM + CSS + Raster Pixel Art):** پس‌زمینه نقاشی‌شده قلعه متروکه و پل سنگی با وضوح بالا و فرمت بهینه WebP (`assets/bg/bg_w1_battle_ruins.webp`).
- **مشعل‌های دیواری متحرک ۱۶ بیتی:** مشعل‌های سنگی با انیمیشن ۴ فریمی زبانه آتش (`assets/fx/fx_torch_flames_strip.png`) و پرتو نور شعاعی ارگانیک بدون بار پردازشی CPU.
- **مه معلق روی جاده و ذرات خاکستر:** مه شناور متحرک در سطح جاده با ترکیب نوری Screen و ذرات طلایی شناور در فضای دژ.
- **شوالیه با ۵ حالت انیمیشنی:** حالت‌های درنگ (Idle)، گام‌برداری (Walk با ضرب‌آهنگ ۲ مرحله‌ای)، ضربه شمشیر (Attack به همراه جرقه‌های ساطع شمشیر)، آسیب/ضربه (Damage با پس‌نشینی و لرزش صفحه) و زانوزدن (Kneel).
- **موانع جاده و غول دروازه:** تله تیغه‌ای مکانیکی (مراحل ۱ و ۲)، خرس سایه‌ها (مراحل ۳ تا ۵) و اژدهای تاریکی (غول دروازه مراحل پایانی و دژ جهنمی).
- **آزادی شاهدخت در دروازه:** با گشوده شدن تمام ۱۰ قفل و پیروزی در مرحله، شاهدخت اسیر با هاله نوری پورتال در آستانه دروازه نمایان شده و شوالیه در برابر او ادای احترام می‌کند.
- **صحنه خاموشی شمع‌ها و شکست (Defeat):** در صورت سوختن هر ۳ شمع، امکان تلاش مجدد مستقیم یا بازگشت به نقشه فراهم است.

### ۲. هویت بصری تفکیک‌شده برای ۴ جهان قلعه
1. **جهان واژگان (World 1 — تم کهربایی `#F0B560`):** دژ باستانی سنگی، مشعل‌های گرم کهربایی، ستون‌های خزه بسته و جاده سنگی قرون وسطایی (۸ مرحله، ۱۶۱ واژه درسی).
2. **قلمرو کنایه (World 2 — تم فیروزه‌ای `#5DE2EB`):** ویرانه‌های سیل‌زده باستانی، انعکاس آب، مه سرد فیروزه‌ای و فانوس‌های اسرارآمیز (۴ مرحله، ۴۰ کنایه منتخب درسی).
3. **بیشه ایهام (World 3 — تم زمردی `#3EA066`):** جنگل کهن و ریشه‌های تنومند معبد باستانی، گرده‌های درخشان و نور زمردین (۲ مرحله، ۲۰ واژه ایهام‌دار).
4. **دژ جهنمی (World 4 — تم زرشکی `#B13E53`):** قلعه گدازه‌ای آتشفشانی، شکاف‌های سوزان، خاکستر مذاب و امتیاز ۲ برابری (۲x XP).

### ۳. حفظ صددرصدی هسته آموزشی و فنی
- حفظ تمامی ۱۵ مرحله درسی، ۱۶۱ واژه، ۴۰ کنایه و ۲۰ ایهام کتاب فارسی دهم.
- آزمون ۴ گزینه‌ای با گزینه‌های انحرافی چالش‌برانگیز و معنایی.
- سیستم مرور بدون استرس فلش‌کارت (Study Mode) با سوایپ و چرخش لمسی.
- احراز هویت با شماره موبایل ۱۱ رقمی و پین ۴ رقمی (رمزنگاری‌شده).
- پنل مخفی دبیر با کد ورود `431380` (۳ کلیک روی شماره نسخه).
- همگام‌سازی ابری زنده با Supabase و جدول رتبه‌بندی درون‌رشته‌ای/کشوری.
- پشتیبانی کامل آفلاین و نصب PWA (سرویس ورکر نسخه `ghale-vajegan-v3.6-visual`).

## نحوه اجرای محلی (Local Run)

برای اجرای محلی این نسخه، کافی است یک وب‌سرور سبک در پوشه پروژه اجرا کنید:

```powershell
# با استفاده از Node.js
npx serve .

# یا با پایتون
python -m http.server 8080
```
سپس در مرورگر به آدرس `http://localhost:8080` (یا پورتی که سرور اعلام می‌کند) مراجعه کنید.

## نحوه استقرار روی GitHub Pages

1. تغییرات را به مخزن GitHub ارسال (Push) کنید:
   ```bash
   git add .
   git commit -m "Deploy Ghale Vajegan v3.6-visual"
   git push origin main
   ```
2. در تنظیمات مخزن (**Settings > Pages**)، شاخه `main` و ریشه `/ (root)` را به عنوان منبع انتشار تایید کنید.
3. بازی به صورت کاملاً مستقل، آفلاین و بدون هیچ پیش‌نیازی روی دامنه شما منتشر خواهد شد.

## نحوه بازگشت به نسخه قبل (Rollback)

در صورتی که به هر دلیلی نیاز به بازگشت به نسخه v3.5.1 باشد، چک‌پوینت ذخیره‌شده است:
```bash
git checkout checkpoint-v3.5.1
```
یا فایل بکاپ خودکار `index.html.bak` را به عنوان `index.html` بازگردانید.
